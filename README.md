# Palash Behura — Resume Website

Simple GitHub Pages-ready personal resume site for Palash Behura.

## Publish with GitHub Pages

1. Create a repository named `palashbehura54-source.github.io` under the GitHub account `palashbehura54-source`.
2. Upload `index.html`, `style.css`, `resume.pdf`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. The site will be published at `https://palashbehura54-source.github.io/` after GitHub Pages finishes publishing.

This is a plain HTML/CSS site with no build step.
